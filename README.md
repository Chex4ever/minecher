# Minecher

Лаунчер Minecraft-серверов с веб-интерфейсом, REST API, централизованными логами и широким набором настроек.

- **Мониторинг и управление** — создание, запуск, остановка, перезапуск и удаление серверов через веб-панель.
- **Поддержка всех основных типов** — Vanilla, Paper, Spigot, Forge, Fabric (включая модпаки) + `custom` для уже существующих серверов.
- **Импорт и экспорт** — перенос существующего сервера из папки или из `.mcs`-архива (и обратно) между установками minecher.
- **Веб-консоль** — полный поток логов и отправка команд в консоль сервера в реальном времени (WebSocket).
- **Централизованные логи** — файлы на диске + индекс в SQLite, поиск и фильтрация.
- **Настройки** — server.properties, JVM-аргументы, память, порт, автостарт и автоперезапуск.
- **Контроль портов** — при создании сервера порт автоматически подбирается свободным (от 25565 вверх), рядом с полем порта — живой индикатор «доступен/занят».
- **Бэкапы** — создание, восстановление и удаление архивов мира.
- **Планировщик** — cron-задачи: start/stop/restart/backup/command.
- **RCON** — команды через RCON-протокол, когда stdin недоступен.
- **Авторизация** — JWT, роли admin / operator / viewer.
- **Встроенный Java runtime** — системная Java не нужна: Temurin JRE автоматически скачивается при первом старте сервера.
- **Готов к запуску из коробки** — EULA принимается автоматически, `online-mode=false` по умолчанию (включается в настройках).

## Требования

- Node.js **>= 20** (разработка велась на Node 24)
- Java **не требуется** — JRE Temurin 25 качается автоматически при первом старте сервера (задать версию можно переменной `MC_JAVA_VERSION`; явный путь к java — поле «Java path» в настройках сервера)
- Доступ в интернет на этапе скачивания jar (Mojang, PaperMC, GetBukkit, MinecraftForge, Fabric) и JRE (Adoptium)

## Быстрый старт

```bash
npm install
npm run dev
```

- Веб-интерфейс: http://localhost:5173
- API: http://localhost:8080/api
- Вход по умолчанию: **admin / admin**

> ⚠️ Обязательно смените пароль администратора (см. переменные окружения ниже).

### Производственный запуск

```bash
npm run build          # сборка types, server (tsc), web (vite)
MC_AUTH_SECRET=... MC_ADMIN_PASSWORD=... npm start -w server
# статические файлы из web/dist можно отдать nginx, проксируя /api на :8080
```

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `MC_HOST` | `0.0.0.0` | IPv4-адрес или имя хоста для API. IPv6 **не поддерживается**. |
| `MC_PORT` | `8080` | Порт API. |
| `MC_DATA_DIR` | `<cwd>/data` | Корневой каталог данных (БД, логи, серверы, бэкапы). |
| `MC_AUTH_SECRET` | `change-me-in-production` | Секрет для подписи JWT. |
| `MC_JWT_EXPIRES` | `7d` | Время жизни токена (формат `vercel/ms`, напр. `2h`, `30d`). |
| `MC_LOG_MAX_BYTES` | `52428800` | Максимальный размер файла лога перед ротацией. |
| `MC_ADMIN_USERNAME` | `admin` | Логин администратора, создаётся при первом запуске. |
| `MC_ADMIN_PASSWORD` | `admin` | Пароль администратора при первом запуске. |
| `MC_JAVA_VERSION` | `25` | Feature-версия встроенного JRE Temurin (скачивается при первом старте). Paper 26.1+ требует Java 25+. |

## Структура проекта

```
packages/types/   Общие TypeScript-типы (MinecraftServer, LogEntry, события...)

```

Подробности — в [docs/](docs/).

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Запускает всё сразу: types (watch), server, web |
| `npm run dev:server` | Только демон API |
| `npm run dev:web` | Только веб-интерфейс |
| `npm run typecheck` | Проверка типов всех воркспейсов |
| `npm run build` | Полная сборка |
| `npm run build -w web` | Сборка только веба |

## Безопасность

- Администратор по умолчанию `admin/admin` создаётся **только** при пустой БД. Задайте `MC_ADMIN_PASSWORD` и/или смените пароль сразу после установки.
- Роли: `viewer` — просмотр, `operator` — управление серверами (start/stop/command), `admin` — удаление серверов, бэкапы-restore, управление пользователями.
- В производственной среде закройте `:8080` из внешней сети (только через nginx + TLS) и задайте надёжный `MC_AUTH_SECRET`.

## Известные ограничения

- **TPS** в статистике пока всегда `null` — для vanilla нет штатного источника; планируется лёгкий плагин (Spark) или сбор через RCON.
- Потоковая передача логов консоли идёт через WebSocket; при работе за прокси нужна поддержка upgrade/`ws` (в dev-прокси Vite она включена).
